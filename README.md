# Financial Data Cleaning and Preparation

## Project Overview
This project focuses on cleaning and preparing a sample financial dataset using Python in Google Colab. The objective is to identify missing values and improve data quality before further analysis.

## Internship Task
- **Company:** Swynex
- **Task:** Data Cleaning and Preparation
- **Tool:** Google Colab
- **Language:** Python
- **Dataset:** Financial Dataset

## Work Performed
1. Imported the financial dataset into Google Colab.
2. Explored the dataset and inspected its structure.
3. Checked for missing or null values.
4. Identified rows containing missing values.
5. Removed 2 rows containing missing values from the 20-row sample.
6. Prepared the cleaned data for potential further analysis.

## Dataset Summary
- Initial sample size: 20 rows
- Rows removed: 2
- Remaining rows: 18
